
# Care Companion Appointment Booking Prototype

A responsive web application prototype inspired by
Care Companion, an elderly care support startup.

## Problem Statement

Families may need help coordinating hospital visits and
support for elderly relatives. This project demonstrates
a simple interface for preparing a visit request.

## Features

- Hospital selection
- Date and time selection
- Minimum 12-hour advance request validation
- Multiple selectable support services
- Form validation
- Demo request preview
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

care-companion-appointment-prototype/
├── index.html
└── README.md

## How to Run

1. Download or clone this repository.
2. Open index.html in a modern web browser.
3. Enter fictional demo information.
4. Select a hospital, date, time and support services.
5. Click Preview Visit Request.

## Limitations

This is a frontend-only educational prototype.
It does not create real bookings, send notifications,
verify hospital availability, or save requests to a database.

The 12-hour validation runs in the browser and is not
a secure server-side booking restriction.

## Future Improvements

- Add a backend using Python and Flask
- Store requests in a database
- Add secure family accounts
